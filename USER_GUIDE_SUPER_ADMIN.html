คู่มือสำหรับผู้ดูแลระบบสูงสุด (Super Admin)

คู่มือนี้เป็น HTML ที่สามารถแก้ไขได้จากหน้า ตั้งค่าระบบเว็บไซต์ โดยตรง.

1. จัดการผู้ใช้

เข้าเมนูจัดการผู้ใช้ เพื่อตรวจสอบ เพิ่ม แก้ไข หรืออนุมัติผู้ใช้งาน.

2. ตั้งค่าประกาศหน้าเว็บ

ใช้เมนูตั้งค่าระบบเว็บไซต์เพื่อแก้ไขข้อความประกาศและรูปประกาศที่จะแสดงเป็น modal บนหน้าแรก.

3. ดูระบบ Dispatch และคลังสินค้า

ตรวจสอบงานจัดส่ง สร้างทีม และบริหารคลังสินค้าในระบบได้ตามสิทธิ์.
