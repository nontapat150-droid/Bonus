👑 Super Admin

คู่มือผู้ดูแลระบบสูงสุด

คุณมีสิทธิ์สูงสุดในระบบ — จัดการผู้ใช้ ตั้งค่าระบบ ประกาศ Dispatch คลังสินค้า และรายงานน้ำมัน

✅ หน้าแรก ✅ ระบบเช็คอิน ✅ น้ำมัน/ยานพาหนะ ✅ ระบบ Dispatch ✅ คลังสินค้า ✅ จัดการผู้ใช้ ✅ ตั้งค่าระบบเว็บไซต์ ✅ ประวัติระบบ
1

เข้าสู่ระบบ

🔐

เปิดเว็บเบราว์เซอร์ → เข้า URL ของระบบ → กรอก ชื่อผู้ใช้ และ รหัสผ่าน → กดปุ่ม "เข้าสู่ระบบ"

หลังล็อกอิน ระบบจะพาไปหน้า Dashboard ซึ่งแสดง KPI สรุปงานวันนี้ ค่าน้ำมัน สต็อกสินค้า และจำนวนพนักงาน

💡

ถ้ากรอกรหัสแล้วเข้าไม่ได้ ตรวจสอบว่า Caps Lock ติดอยู่หรือเปล่า หรือว่ามีช่องว่างต่อท้ายชื่อผู้ใช้หรือไม่

2

จัดการผู้ใช้และสิทธิ์

👥

คลิกเมนู จัดการผู้ใช้ ด้านซ้ายมือ เพื่อดูรายชื่อพนักงานทั้งหมดและบทบาทของแต่ละคน

  • + เพิ่มกดปุ่ม "+ เพิ่มผู้ใช้" → กรอกชื่อ, ชื่อผู้ใช้, รหัสผ่าน, เลือกบทบาท → กด "บันทึก"
  • ✏️ แก้ไขกดปุ่มดินสอหน้าชื่อผู้ใช้ → แก้ไขข้อมูล → กด "บันทึก"
  • 🗑️ ลบกดปุ่มถังขยะ → ระบบจะถามยืนยัน → กด "ยืนยัน" เพื่อลบถาวร
  • 🔄 บทบาทเลือกบทบาทให้เหมาะสม: super_admin / admin / technician / sales / user
⚠️

การลบผู้ใช้เป็นการลบถาวร ไม่สามารถกู้คืนได้ ควรตรวจสอบให้ดีก่อนยืนยัน

3

ตั้งค่าระบบเว็บไซต์

⚙️

คลิกเมนู ตั้งค่าระบบเว็บไซต์ เพื่อจัดการประกาศที่แสดงบนหน้าเว็บ มีสองรูปแบบ:

  • 🪟 ป๊อปอัปแสดงเป็นหน้าต่างกลางจอเมื่อผู้ใช้เข้าสู่ระบบ — ใส่หัวข้อ, ข้อความ, และรูปประกอบ (ไม่บังคับ)
  • 📢 ป้ายวิ่งแสดงเป็นแถบวิ่งด้านบนหน้าแรก — ใส่ข้อความที่ต้องการให้วิ่งแสดง

กรอกข้อมูลและกด "บันทึก" ประกาศจะแสดงทันทีสำหรับทุกคน

📅

ตั้ง "ระยะเวลาที่แสดง" ได้ (เช่น 3 วัน) เพื่อให้ประกาศหมดอายุอัตโนมัติ ไม่ต้องลบเอง

4

ระบบ Dispatch — จัดส่งอัจฉริยะ

🗺️

เมนู ระบบจัดส่งอัจฉริยะ ใช้สำหรับสร้างและมอบหมายงานให้ทีมช่างเทคนิค

  • สร้างทีมแถบ "ทีม" → กดปุ่ม "+ สร้างทีม" → ตั้งชื่อทีม → เพิ่มสมาชิก
  • + งานกดปุ่ม "+ เพิ่มงาน" → กรอกชื่อลูกค้า, ที่อยู่ → ปักหมุดบนแผนที่ → เลือกทีม
  • ⚡ อัตโนมัติกดปุ่ม "จ่ายงานอัตโนมัติ" ระบบจะคำนวณเส้นทางและแบ่งงานให้ทุกทีมเอง
  • 📍 แผนที่ดูตำแหน่งงานทุกจุดได้บนแผนที่แบบเรียลไทม์
⚠️

สำคัญ: ตอนสร้างงานต้อง ปักหมุดตำแหน่งบนแผนที่ด้วยทุกครั้ง มิฉะนั้นงานจะไม่แสดงในแผนที่และระบบ auto-assign ไม่ทำงาน

5

ระบบคลังสินค้า

📦

เมนู ระบบคลังสินค้า จัดการสต็อกสินค้า ตรวจสอบของคงเหลือ และโอนสินค้าระหว่างคลัง

  • 🔍 ดูเลื่อนดูรายการสินค้า กรองด้วยชื่อ รหัส หรือสถานะ
  • + เพิ่มกดปุ่ม "+ เพิ่มสินค้า" → กรอกชื่อ, รหัส, จำนวน → กด "บันทึก"
  • ✏️ แก้ไขกดปุ่มดินสอหน้าสินค้า → แก้ไขข้อมูล → บันทึก
  • 🔄 โอนกดปุ่ม "โอนสินค้า" → เลือกสินค้าและปลายทาง → ยืนยัน
  • 📥 นำเข้ากดปุ่ม "นำเข้า Excel" → เลือกไฟล์ → ระบบอ่านข้อมูลอัตโนมัติ
6

รายงานน้ำมันและยานพาหนะ

⛽

เมนู น้ำมันและยานพาหนะ แสดงรายงานการเติมน้ำมันของทุกทีม วิเคราะห์ค่าใช้จ่ายและประสิทธิภาพ

  • 📅 กรองใช้ตัวกรอง วันที่ และ ทีม/รถ เพื่อดูข้อมูลเฉพาะกลุ่ม
  • 📊 วิเคราะห์ดู km/l อัตราการสิ้นเปลืองน้ำมันของแต่ละรถ
  • 📤 ส่งออกกดปุ่ม "ส่งออก Excel" ดาวน์โหลดรายงานเพื่อนำไปใช้ต่อ
📊

เปรียบเทียบ km/l ระหว่างรถแต่ละคัน ถ้ารถคันไหน km/l ต่ำกว่าปกติมากอาจต้องตรวจสอบสภาพเครื่อง

7

ระบบเช็คอิน

📋

เมนู ระบบเช็คอิน บันทึกการเข้า-ออกงานของพนักงาน คุณสามารถดูประวัติและสถานะปัจจุบันของทุกคน

  • 👁 ดูดูสถานะเช็คอิน/เช็คเอาต์ปัจจุบันของพนักงานทุกคน
  • 📜 ประวัติดูประวัติย้อนหลังรายวัน รายสัปดาห์ หรือรายเดือน
8

ออกจากระบบ

🚪

กดชื่อผู้ใช้หรือไอคอนที่มุมซ้ายล่างของ sidebar → กด "ออกจากระบบ" ทุกครั้งหลังใช้งานเสร็จ

⚠️

ห้ามปิดหน้าต่างเบราว์เซอร์โดยไม่ logout — บัญชี super_admin มีสิทธิ์สูงมาก หากคนอื่นเข้าถึงได้อาจเกิดความเสียหาย

🆘 ปัญหาที่พบบ่อย แก้ได้เอง
อาการที่พบวิธีแก้ไข
เข้าสู่ระบบไม่ได้ พบบ่อย ตรวจสอบ Caps Lock, ช่องว่าง และความถูกต้องของรหัสผ่าน ถ้ายังไม่ได้ลอง reset รหัสผ่านผ่าน File Manager
เมนูบางอันหายไป พบบ่อย ออกจากระบบและเข้าใหม่ หรือ refresh หน้า (Ctrl+F5) เพื่อล้าง cache
สร้างงานแล้วไม่แสดงบนแผนที่ ตรวจสอบว่าได้ปักหมุดตำแหน่งบนแผนที่ตอนสร้างงานหรือไม่ ถ้ายังไม่มีให้แก้ไขงานแล้วปักหมุดใหม่
ประกาศป๊อปอัปไม่แสดง ตรวจสอบว่า "ระยะเวลาที่แสดง" ยังไม่หมดอายุ และข้อความ/หัวข้อกรอกครบ กดรีเฟรชข้อมูลแล้วบันทึกใหม่
รูปประกาศอัปโหลดไม่ได้ ไฟล์รูปต้องมีขนาด ไม่เกิน 5 MB และเป็น .jpg, .png, .gif, หรือ .webp เท่านั้น
นำเข้า Excel คลังสินค้าไม่ได้ ตรวจสอบรูปแบบไฟล์ว่าเป็น .xlsx หรือ .csv ที่รองรับ และตรวจหัวตาราง (Header) ว่าตรงกับที่ระบบกำหนด
จ่ายงานอัตโนมัติไม่ทำงาน ตรวจสอบว่ามีทีมที่พร้อมใช้งานและงานมีพิกัด GPS ครบทุกรายการ ถ้าไม่มีทีม ให้สร้างทีมก่อน
ส่งออก Excel น้ำมันไม่ได้ ลองใช้เบราว์เซอร์อื่น (Chrome หรือ Edge) และตรวจว่า Pop-up Blocker ไม่ได้บล็อกการดาวน์โหลด
