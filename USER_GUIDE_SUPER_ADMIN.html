คู่มือสำหรับผู้ดูแลระบบสูงสุด (Super Admin)

คู่มือนี้ให้ภาพรวมของทุกฟังก์ชันที่ผู้ดูแลระบบสูงสุดสามารถจัดการได้ ทั้งผู้ใช้ ระบบ การจัดส่ง คลังสินค้า และความปลอดภัยของระบบ

1️⃣ Dashboard Overview

หน้าจอหลักแสดงเมนูสำคัญทั้งหมด เช่น การจัดการผู้ใช้ การตั้งค่าระบบ การจัดส่งและคงคลัง

  • เมนู ตั้งค่าระบบเว็บไซต์ เพื่อแก้ไขคู่มือและประกาศ
  • เมนู จัดการผู้ใช้ เพื่อเพิ่ม แก้ไข หรือลบผู้ใช้ และตั้งบทบาท
  • เมนู Dispatch เพื่อดูสถานะงานทั้งหมด

2️⃣ User Management

สร้าง, แก้ไข, อนุมัติผู้ใช้และกำหนดบทบาท (admin, technician, sales) รวมถึงรีเซ็ตรหัสผ่าน

3️⃣ System Settings

แก้ไขประกาศหน้าเว็บ, อัปโหลดรูปประกาศ, ปรับข้อความโฆษณา และตั้งค่าข้อมูลพื้นฐานของเว็บไซต์

4️⃣ Dispatch Management

ดูและกำหนดทีม, กำหนดงานให้ช่าง, ตรวจสอบสถานะการจัดส่งแบบเรียลไทม์

5️⃣ Inventory & Oil Reports

ตรวจสอบสต็อกสินค้า, รายงานการเติมน้ำมัน, ส่งออกและนำเข้าไฟล์ Excel

6️⃣ Security & Backup

ตั้งค่าการรักษาความปลอดภัย, นโยบายรหัสผ่าน, สำรองและกู้คืนฐานข้อมูล

กลับสู่หน้าแรก

คู่มือสำหรับผู้ดูแลระบบสูงสุด (Super Admin)

คู่มือนี้เป็น HTML ที่สามารถแก้ไขได้จากหน้า ตั้งค่าระบบเว็บไซต์ โดยตรง.

1. จัดการผู้ใช้

เข้าเมนูจัดการผู้ใช้ เพื่อตรวจสอบ เพิ่ม แก้ไข หรืออนุมัติผู้ใช้งาน.

2. ตั้งค่าประกาศหน้าเว็บ

ใช้เมนูตั้งค่าระบบเว็บไซต์เพื่อแก้ไขข้อความประกาศและรูปประกาศที่จะแสดงเป็น modal บนหน้าแรก.

3. ดูระบบ Dispatch และคลังสินค้า

ตรวจสอบงานจัดส่ง สร้างทีม และบริหารคลังสินค้าในระบบได้ตามสิทธิ์.
