⚙️ Admin

คู่มือผู้ดูแลระบบ (Admin)

คุณสามารถจัดการงาน ทีม คลังสินค้า รายงานน้ำมัน และประกาศได้ — แต่ไม่สามารถจัดการผู้ใช้หรือตั้งค่าระบบได้

✅ หน้าแรก ✅ ระบบเช็คอิน ✅ น้ำมัน/ยานพาหนะ ✅ ระบบ Dispatch ✅ คลังสินค้า 🚫 จัดการผู้ใช้ 🚫 ตั้งค่าระบบเว็บไซต์

🛡️ ขอบเขตสิทธิ์ Admin: คุณสามารถดูและจัดการ ข้อมูลปฏิบัติการ ทั้งหมดได้ แต่การ จัดการบัญชีผู้ใช้ และ ตั้งค่าระบบ ต้องติดต่อ Super Admin

1

เข้าสู่ระบบ

🔐

เปิดเว็บเบราว์เซอร์ → เข้า URL ของระบบ → กรอก ชื่อผู้ใช้ และ รหัสผ่าน → กดปุ่ม "เข้าสู่ระบบ"

เมื่อเข้าสู่ระบบแล้ว ระบบจะพาไปหน้า Dashboard แสดงสรุปงาน KPI วันนี้ และเมนูต่างๆ ที่คุณมีสิทธิ์ใช้งาน

💡

ถ้ากรอกรหัสแล้วเข้าไม่ได้ ตรวจสอบว่า Caps Lock ติดอยู่หรือเปล่า หรือมีช่องว่างที่ไม่ต้องการ

2

ระบบ Dispatch — จัดการงานและทีม

🗺️

คลิกเมนู ระบบจัดส่งอัจฉริยะ เพื่อสร้างงาน จัดทีม และติดตามสถานะงาน

การสร้างงาน:

  • 1กดปุ่ม "+ เพิ่มงาน"
  • 2กรอก ชื่อลูกค้า, ที่อยู่, รายละเอียดงาน
  • 3ปักหมุดตำแหน่งบนแผนที่ — สำคัญมาก!
  • 4เลือกทีมที่จะมอบหมาย → กด "บันทึก"

การจ่ายงานอัตโนมัติ:

  • ⚡กดปุ่ม "จ่ายงานอัตโนมัติ" ระบบจะคำนวณเส้นทางที่เหมาะสมและแบ่งงานให้ทุกทีมเอง

การจัดการทีม:

  • + ทีมกดปุ่ม "+ สร้างทีม" → ตั้งชื่อ → เพิ่มสมาชิก → บันทึก
  • ✏️ แก้ไขกดดินสอหน้าชื่อทีม → แก้ชื่อหรือสมาชิก → บันทึก
⚠️

ต้องปักหมุดแผนที่ทุกครั้ง มิฉะนั้นระบบ auto-assign ไม่สามารถคำนวณเส้นทางได้

3

ระบบคลังสินค้า

📦

คลิกเมนู ระบบคลังสินค้า เพื่อดูและจัดการสต็อกสินค้าทั้งหมด

  • 🔍 ค้นหาพิมพ์ชื่อหรือรหัสสินค้าในช่องค้นหา ระบบจะกรองผลทันที
  • + เพิ่มกดปุ่ม "+ เพิ่มสินค้า" → กรอกชื่อ รหัส จำนวน → กด "บันทึก"
  • ✏️ แก้ไขกดปุ่มดินสอหน้าสินค้า → แก้ไข → บันทึก
  • 🔄 โอนกดปุ่ม "โอนสินค้า" → เลือกปลายทางและจำนวน → ยืนยัน
  • 📥 Excelกดปุ่ม "นำเข้า Excel" เพื่ออัปโหลดข้อมูลสินค้าจำนวนมากพร้อมกัน
📋

ก่อนนำเข้า Excel ตรวจสอบว่า หัวคอลัมน์ ตรงกับรูปแบบที่ระบบกำหนด

4

รายงานน้ำมันและยานพาหนะ

⛽

คลิกเมนู น้ำมันและยานพาหนะ เพื่อดูรายงานการใช้น้ำมันและวิเคราะห์ต้นทุนของแต่ละทีม

  • 📅 กรองเลือกช่วงวันที่ เลือกทีมหรือรถ แล้วกด "ค้นหา"
  • 📊 วิเคราะห์ดูตาราง km/l อัตราการสิ้นเปลืองน้ำมันของแต่ละรถแต่ละวัน
  • 📤 ส่งออกกดปุ่ม "ส่งออก Excel" เพื่อดาวน์โหลดรายงานเป็นไฟล์ตาราง
✅

ใช้รายงานน้ำมันเพื่อ ตรวจจับความผิดปกติ หากรถคันใดใช้น้ำมันมากกว่าปกติอาจต้องส่งซ่อม

5

ดูประวัติการเช็คอิน

📋

คลิกเมนู ระบบเช็คอิน เพื่อดูสถานะการเข้า-ออกงานของพนักงานทุกคน

  • 👁 สถานะดูว่าพนักงานคนใดกำลังทำงาน (เช็คอินแล้ว) หรือยังไม่มา
  • 📜 ประวัติเลือกวันที่เพื่อดูประวัติย้อนหลัง
6

ส่งการแจ้งเตือนให้ทีม

🔔

กดปุ่มกระดิ่ง 🔔 มุมบนขวา → กดปุ่ม เพิ่มการแจ้งเตือน เพื่อส่งข้อความถึงทีม

  • 📢 ทุกคนเลือก "ส่งให้ทุกคน" เพื่อ broadcast ข้อความไปยังพนักงานทุกคน
  • 🚗 ทีมเลือก "ส่งเป็นทีม" แล้วเลือกชื่อทีมที่ต้องการ
  • 👤 บุคคลเลือก "ส่งรายบุคคล" แล้วเลือกชื่อพนักงาน
💡

การแจ้งเตือนจะปรากฏในกระดิ่งของผู้รับทันที สามารถส่งข้อมูลเร่งด่วนได้

7

ออกจากระบบ

🚪

กดชื่อผู้ใช้ที่มุมล่างซ้ายของ sidebar → กด "ออกจากระบบ" ทุกครั้งหลังใช้งานเสร็จ

⚠️

อย่าปิดหน้าต่างเบราว์เซอร์โดยไม่ logout โดยเฉพาะในเครื่องสาธารณะ

🆘 ปัญหาที่พบบ่อย แก้ได้เอง
อาการที่พบวิธีแก้ไข
เข้าสู่ระบบไม่ได้ พบบ่อย ตรวจสอบ Caps Lock และช่องว่าง ถ้าลืมรหัสผ่านให้ติดต่อ Super Admin เพื่อรีเซ็ต
ไม่เห็นเมนูคลังสินค้าหรือ Dispatch พบบ่อย ออกจากระบบแล้วเข้าใหม่ หากยังไม่เห็น ติดต่อ Super Admin ตรวจสอบสิทธิ์บัญชีของคุณ
สร้างงานแล้วไม่ขึ้นบนแผนที่ แก้ไขงานนั้นแล้วปักหมุดตำแหน่งบนแผนที่อีกครั้ง แล้วบันทึก
จ่ายงานอัตโนมัติไม่ทำงาน ตรวจสอบว่ามีทีมที่พร้อมใช้งาน และงานทุกรายการมีพิกัด GPS ครบ
นำเข้า Excel คลังสินค้าไม่ได้ ตรวจสอบรูปแบบไฟล์และหัวคอลัมน์ให้ตรงกับ Template ของระบบ
ส่งออก Excel น้ำมันไม่ได้ ตรวจสอบว่า Pop-up Blocker ในเบราว์เซอร์ไม่ได้บล็อกการดาวน์โหลด ลองใช้ Chrome
ต้องการแก้ไขบัญชีผู้ใช้ Admin ไม่มีสิทธิ์จัดการบัญชีผู้ใช้ ต้องติดต่อ Super Admin เพื่อดำเนินการ
