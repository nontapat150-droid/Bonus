คู่มือสำหรับผู้ดูแลระบบ (Admin)

คู่มือนี้อธิบายการจัดการ Dispatch, รายงานน้ำมัน, คลังสินค้า, และการแก้ไขประกาศเว็บไซต์

1️⃣ Dispatch Operations

สร้างทีม, กำหนดงานให้ช่าง, ตรวจสอบสถานะการจัดส่ง และบันทึกผลลัพธ์

2️⃣ Oil Report Management

บันทึกการเติมน้ำมันประจำวัน, แก้ไขบันทึก, ส่งออก/นำเข้าไฟล์ Excel

3️⃣ Inventory Controls

เพิ่ม/แก้ไขสินค้า, ตรวจสอบสต็อก, โอนสินค้าระหว่างคลัง

4️⃣ Announcement Editing

แก้ไขข้อความและรูปภาพของประกาศหน้าเว็บที่แสดงเป็นโมดัลบนหน้าแรก

5️⃣ Basic User Oversight

ดูรายชื่อผู้ใช้, รีเซ็ตรหัสผ่าน, ตรวจสอบบทบาทผู้ใช้

คู่มือสำหรับผู้ดูแลระบบ (Admin)

คู่มือนี้เป็น HTML ที่รองรับการแก้ไขได้จากหน้า ตั้งค่าระบบเว็บไซต์.

1. ระบบจัดส่ง

ใช้เมนู Dispatch เพื่อดูรายการงาน สร้างทีม และจ่ายงานอัตโนมัติ.

2. น้ำมันและรายงาน

  • ดูรายงานน้ำมัน
  • ส่งออกไฟล์ Excel
  • นำเข้าไฟล์ Excel หากจำเป็น

3. ระบบคลังสินค้า

ตรวจสอบสต็อก เพิ่ม/แก้ไขสินค้า และโอนสินค้าระหว่างคลัง.
