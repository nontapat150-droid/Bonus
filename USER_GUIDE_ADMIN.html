👑 Super Admin

คู่มือผู้ดูแลระบบสูงสุด

คุณมีสิทธิ์เข้าถึงและจัดการได้ทุกอย่างในระบบ — ทั้งผู้ใช้งาน งาน คลังสินค้า และความปลอดภัย

1

เข้าสู่ระบบ

เปิดเว็บไซต์ขึ้นมา จะเห็นหน้าให้กรอกชื่อผู้ใช้และรหัสผ่าน กรอกให้ครบแล้วกดปุ่ม "เข้าสู่ระบบ" ระบบจะพาไปหน้าแรก (Dashboard) ที่แสดงภาพรวมทั้งหมด

💡

ถ้ากรอกรหัสแล้วเข้าไม่ได้ ให้ตรวจสอบว่ากด Caps Lock ติดอยู่หรือเปล่า

2

ตั้งค่าเว็บไซต์

ที่เมนูด้านซ้ายมือ ให้มองหาคำว่า "ตั้งค่าระบบเว็บไซต์" แล้วคลิก ตรงนี้คือที่สำหรับปรับแต่งการทำงานของระบบทั้งหมด เช่น ชื่อบริษัท เวลาทำงาน ฯลฯ

⚠️

เมื่อปรับเสร็จทุกครั้ง อย่าลืมกดบันทึก ไม่งั้นการตั้งค่าจะหายไป

3

จัดการสมาชิก

คลิกเมนู "จัดการผู้ใช้" จะเห็นรายชื่อทุกคนในระบบ ทำได้ดังนี้

  • + เพิ่มกดปุ่ม "+ เพิ่มผู้ใช้" แล้วกรอกข้อมูลให้ครบ
  • ✏️ แก้ไขกดปุ่มดินสอหน้าชื่อคนที่ต้องการเปลี่ยนข้อมูล
  • 🗑️ ลบกดปุ่มถังขยะแล้วกด "ยืนยัน" อีกครั้ง
⚠️

กด "บันทึก" ทุกครั้งหลังทำการเปลี่ยนแปลง

4

โพสต์ประกาศ

คลิกเมนู "ประกาศ" หรือ "ข่าวสาร" → กรอกหัวข้อ → ใส่รายละเอียด → แนบรูป (ถ้ามี) → กดบันทึก ทุกคนในระบบจะเห็นประกาศนี้ทันที

⚠️

รูปที่แนบต้องขนาด ไม่เกิน 5 MB และต้องเป็นไฟล์ .jpg หรือ .png เท่านั้น

5

กำหนดงานและทีม (Dispatch)

คลิกเมนู "แจกจ่ายงาน (Dispatch)" แล้วทำตามลำดับ

  • ทีมกดปุ่ม "สร้างทีม" → ตั้งชื่อทีม → เพิ่มสมาชิก
  • งานกดปุ่ม "+ เพิ่มงาน" → กรอกรายละเอียดและที่อยู่ → ปักหมุดบนแผนที่
  • สดดูสถานะงานแบบเรียลไทม์ได้เลย ไม่ต้องรีเฟรช
⚠️

สำคัญมาก: ตอนสร้างงาน ต้องปักหมุดตำแหน่งบนแผนที่ด้วยทุกครั้ง ไม่งั้นงานจะไม่แสดงในแผนที่

6

จัดการคลังสินค้า

คลิกเมนู "คลังสินค้า" จะเห็นรายการสินค้าทั้งหมด

  • ดูเลื่อนดูรายการสินค้าได้เลย กรองด้วยชื่อหรือรหัสได้
  • + เพิ่มกดปุ่ม "+ เพิ่ม" → กรอกชื่อสินค้าและรายละเอียด
  • ✏️ แก้ไขกดปุ่มดินสอหน้าสินค้าที่ต้องการแก้ไข
  • 🔄 โอนกดปุ่ม "โอน" เลือกปลายทาง แล้วยืนยัน
7

รายงานน้ำมัน

คลิกเมนู "รายงานน้ำมัน" จะเห็นข้อมูลการใช้น้ำมันของแต่ละทีม เช็คได้ว่าวิ่งกี่กิโล ใช้น้ำมันไปเท่าไหร่ คุ้มแค่ไหน

📊

กดปุ่ม "ส่งออก Excel" เพื่อดาวน์โหลดรายงานเป็นไฟล์ตาราง เปิดใน Excel ได้เลย

8

ความปลอดภัยและสำรองข้อมูล

คลิกเมนู "ความปลอดภัย" มีสิ่งที่ต้องทำ 3 อย่าง

  • 🔒 รหัสนโยบายรหัสผ่าน — ตั้งว่ารหัสต้องกี่ตัว ต้องมีตัวเลขหรือเปล่า ฯลฯ
  • 💾 Backupกดปุ่ม "สำรองข้อมูล" เพื่อบันทึกข้อมูลทั้งหมดไว้
  • ↩️ Restoreถ้าข้อมูลหาย กดปุ่มนี้เพื่อคืนค่าจากที่สำรองไว้
💡

ควรทำ Backup ทุกสัปดาห์ เพื่อป้องกันข้อมูลสูญหาย

9

แก้ไขคู่มือการใช้งาน

ถ้าต้องการแก้ไขคู่มือนี้ ให้เข้าไปที่ File Manager แล้วเปิดไฟล์ชื่อ USER_GUIDE.html แก้ไขข้อความได้เลย แล้วกดบันทึก

10

ออกจากระบบ

กดชื่อหรือรูปโปรไฟล์ที่มุมบนขวา แล้วกด "ออกจากระบบ" ทุกครั้งที่ใช้งานเสร็จ

⚠️

ห้ามปิดแท็บเลยโดยไม่ Logout เพราะคนอื่นอาจเข้ามาใช้บัญชีของคุณได้

🆘 ถ้าเจอปัญหา แก้ได้เอง
อาการที่พบ วิธีแก้ไข
เมนูบางอันหายไป พบบ่อย ออกจากระบบแล้วเข้าใหม่ ถ้ายังหายอยู่ ให้ติดต่อผู้พัฒนาระบบ
โพสต์ประกาศแล้วรูปไม่ขึ้น รูปอาจใหญ่เกิน 5 MB ให้ย่อขนาดก่อน หรือเปลี่ยนเป็นไฟล์ .jpg / .png
สร้างงานแล้วไม่เห็นบนแผนที่ ตอนสร้างงาน อย่าลืมปักหมุดตำแหน่งบนแผนที่ด้วยทุกครั้ง
สำรองข้อมูลไม่สำเร็จ ลองกดใหม่อีกครั้ง ถ้ายังไม่ได้ ให้แจ้งผู้พัฒนาระบบ
แก้ไขคู่มือจากหน้าเว็บไม่ได้ เข้าไปแก้ไฟล์ USER_GUIDE.html ตรงๆ ผ่าน File Manager แทน
🏠 กลับสู่หน้าแรก
