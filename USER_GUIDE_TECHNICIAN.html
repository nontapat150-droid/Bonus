คู่มือสำหรับช่างเทคนิค

คู่มือนี้เป็นเวอร์ชัน HTML ที่ผู้ดูแลระบบสูงสุดสามารถแก้ไขได้จากหน้า ตั้งค่าระบบเว็บไซต์.

1. เข้าสู่ระบบ

ล็อกอินด้วยบัญชีช่างเทคนิคเพื่อเข้าถึงหน้าระบบเช็คอิน น้ำมัน และ Dispatch (หากมีสิทธิ์).

2. ระบบเช็คอิน

  • เลือกเมนู ระบบเช็คอิน
  • เช็คอินเมื่อเริ่มงาน
  • เช็คเอาต์เมื่อเสร็จงาน

3. น้ำมันและยานพาหนะ

ใช้หน้าส่วนนี้เพื่อตรวจสอบการเติมน้ำมัน และบันทึกรายการย้อนหลัง.

4. ระบบจัดส่ง

ถ้ามีเมนู Dispatch ให้ตรวจสอบงานที่ได้รับและตำแหน่งบนแผนที่ก่อนออกปฏิบัติงาน.
