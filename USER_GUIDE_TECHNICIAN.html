🔧 ช่างเทคนิค

คู่มือสำหรับช่างเทคนิค

คู่มือสำหรับการทำงานภาคสนาม — เช็คอิน บันทึกน้ำมัน และดูงาน Dispatch

✅ หน้าแรก ✅ ระบบเช็คอิน ✅ บันทึกน้ำมัน ✅ ดูงาน Dispatch ✅ ประวัติปิดงาน 🚫 คลังสินค้า 🚫 จัดการผู้ใช้ 🚫 ตั้งค่าระบบ

🔧 บทบาทของคุณ: ช่างเทคนิคมีสิทธิ์ใช้งาน เฉพาะส่วนที่เกี่ยวกับการทำงานภาคสนาม ได้แก่ เช็คอิน บันทึกน้ำมัน และดูสถานะงาน Dispatch

1

เข้าสู่ระบบ

🔐

เปิดเว็บเบราว์เซอร์ → เข้า URL ของระบบ → กรอก ชื่อผู้ใช้ และ รหัสผ่าน → กดปุ่ม "เข้าสู่ระบบ"

หลังล็อกอิน คุณจะเห็นเฉพาะเมนูที่เกี่ยวกับการทำงานของช่างเทคนิค เมนูอื่นจะไม่แสดงขึ้น

💡

ถ้ากรอกรหัสแล้วเข้าไม่ได้ ตรวจสอบว่า Caps Lock ติดอยู่หรือเปล่า ถ้าลืมรหัสให้ติดต่อ Admin

2

การเช็คอินเริ่มงาน

✅

คลิกเมนู ระบบเช็คอิน เพื่อบันทึกการเริ่มงานประจำวัน ต้องทำทุกวันก่อนเริ่มทำงาน

เปิดเมนูเช็คอิน → กดปุ่ม "เช็คอิน" → ยืนยันตำแหน่ง → เริ่มทำงานได้
  • 1คลิกเมนู "ระบบเช็คอิน" จากแถบเมนูซ้ายมือ
  • 2กดปุ่ม "เช็คอิน" หรือ "เริ่มงาน" ที่หน้าจอ
  • 3ระบบอาจขอตำแหน่ง GPS → กด "อนุญาต" เพื่อบันทึกตำแหน่ง
  • 4สถานะจะเปลี่ยนเป็น "กำลังทำงาน" สีเขียว
⚠️

ต้องเช็คอิน ก่อนเริ่มทำงานทุกวัน — ถ้าลืมเช็คอิน ให้แจ้ง Admin เพื่อบันทึกให้

3

การเช็คเอาต์เลิกงาน

🏁

เมื่อเลิกงาน ต้องเช็คเอาต์ทุกครั้งเพื่อบันทึกเวลาออกงาน

เปิดเมนูเช็คอิน → กดปุ่ม "เช็คเอาต์" → ยืนยัน → เลิกงานสำเร็จ
  • 1กลับเข้าเมนู "ระบบเช็คอิน"
  • 2กดปุ่ม "เช็คเอาต์" หรือ "จบงาน"
  • 3กด "ยืนยัน" ในกล่องข้อความที่ขึ้นมา
  • 4สถานะจะเปลี่ยนเป็น "เลิกงานแล้ว"
✅

ระบบจะบันทึกเวลาเช็คอินและเช็คเอาต์ไว้อัตโนมัติ ไม่ต้องจดเอง

4

บันทึกข้อมูลน้ำมัน

⛽

ทุกครั้งที่เติมน้ำมัน ต้องบันทึกข้อมูลเข้าระบบทันที คลิกเมนู น้ำมันและยานพาหนะ

ขั้นตอนการบันทึก:

  • 1คลิกเมนู "น้ำมันและยานพาหนะ"
  • 2กดปุ่ม "+ เพิ่มข้อมูล" หรือ "บันทึกน้ำมัน"
  • 3กรอกข้อมูลให้ครบ:
    • วันที่
    • เลือกรถ/ทีม
    • จำนวนลิตรที่เติม
    • เลขไมล์ปัจจุบัน (km)
    • ราคาต่อลิตร
  • 4กดปุ่ม "บันทึก" ระบบจะคำนวณค่าใช้จ่ายและ km/l ให้อัตโนมัติ
📌

สำคัญ: กรอก เลขไมล์ให้ถูกต้อง ทุกครั้ง เพราะระบบใช้คำนวณ km/l หากเลขผิดจะทำให้รายงานผิดพลาด

5

ดูงาน Dispatch

🗺️

คลิกเมนู ระบบจัดส่งอัจฉริยะ เพื่อดูรายการงานที่ได้รับมอบหมายสำหรับทีมของคุณ

  • 📋 รายการดูรายการงานและรายละเอียดของแต่ละงาน
  • 📍 แผนที่กดปุ่ม "ดูแผนที่" หรือกดที่พิน 📍 เพื่อดูตำแหน่งของงานบนแผนที่
  • 📊 สถานะดูสถานะงานปัจจุบัน: รอดำเนินการ / กำลังทำ / เสร็จสิ้น
ℹ️

ช่างเทคนิคสามารถ ดู งานได้ แต่การเพิ่ม แก้ไข หรือจ่ายงานต้องทำโดย Admin หรือ Super Admin

6

ดูประวัติปิดงาน

📜

คลิกเมนู ประวัติปิดงาน เพื่อดูรายการงานที่เสร็จสิ้นแล้วของทีมคุณ สามารถกรองด้วยช่วงวันที่ได้

📋

ใช้ประวัติปิดงานเพื่อ ยืนยันกับ Admin ว่างานที่ทำเสร็จแล้วถูกบันทึกครบถ้วน

7

ออกจากระบบ

🚪

กดชื่อหรือปุ่ม Logout ที่มุมซ้ายล่างของเมนู หรือกดเมนู "ออกจากระบบ" ทุกครั้งหลังเลิกงาน

⚠️

โดยเฉพาะถ้าใช้โทรศัพท์ส่วนกลาง ต้อง logout ทุกครั้ง เพื่อป้องกันคนอื่นเข้าใช้บัญชีของคุณ

🆘 ปัญหาที่พบบ่อย แก้ได้เอง
อาการที่พบวิธีแก้ไข
เข้าสู่ระบบไม่ได้ พบบ่อย ตรวจสอบ Caps Lock และช่องว่างในชื่อผู้ใช้ ถ้าลืมรหัสผ่านให้ติดต่อ Admin เพื่อรีเซ็ต
กดเช็คอินแล้วไม่บันทึก พบบ่อย ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต รีเฟรชหน้า (F5) แล้วลองใหม่ ถ้ายังไม่ได้แจ้ง Admin
ไม่เห็นงาน Dispatch ของตัวเอง รีเฟรชหน้าหรือล็อกอินใหม่ ถ้ายังไม่เห็นแจ้ง Admin ว่างานยังไม่ได้รับการมอบหมาย
กรอกข้อมูลน้ำมันผิด แจ้ง Admin เพื่อแก้ไขหรือลบรายการที่ผิด ช่างไม่สามารถแก้ไขรายการที่บันทึกแล้วได้
หน้าจอค้างหรือโหลดช้า พบบ่อย ตรวจสอบสัญญาณอินเทอร์เน็ต รีเฟรชหน้า (F5 หรือ pull-to-refresh บนมือถือ)
ไม่เห็นเมนูบางอัน ช่างเทคนิคไม่มีสิทธิ์ใช้คลังสินค้า จัดการผู้ใช้ หรือตั้งค่าระบบ — เป็นเรื่องปกติ
บันทึกน้ำมันแล้วตัวเลขผิด แจ้ง Admin ทันที เพื่อแก้ไขก่อนที่รายงานจะถูกปิด ให้บอกวันที่ เลขไมล์ และจำนวนลิตรที่ถูกต้อง
