คู่มือสำหรับผู้ใช้งานทั่วไป

คู่มือนี้เป็นเวอร์ชัน HTML ที่สามารถแก้ไขได้จากหน้า ตั้งค่าระบบเว็บไซต์ โดยผู้ดูแลระบบสูงสุด.

1. เข้าสู่ระบบ

  1. เปิดเว็บเบราว์เซอร์
  2. กรอกชื่อผู้ใช้และรหัสผ่าน
  3. กดปุ่ม เข้าสู่ระบบ

หาก ระบบแจ้งให้ล็อกอินใหม่ ให้ลองล็อกอินใหม่อีกครั้ง.

2. เมนูหลัก

  • หน้าแรก
  • ระบบเช็คอิน
  • น้ำมันและยานพาหนะ
  • ระบบจัดส่งอัจฉริยะ
  • ระบบคลังสินค้า (สำหรับ admin / super_admin)
  • จัดการผู้ใช้ (สำหรับ super_admin)

3. การใช้งานที่ควรรู้

เมนูที่คุณเห็นจะขึ้นอยู่กับบทบาทของคุณ หากไม่เห็นเมนูใด แปลว่าไม่มีสิทธิ์ใช้งานสำหรับเมนูนั้น.

4. ออกจากระบบ

กดปุ่ม ออกจากระบบ และล็อกอินใหม่เมื่อจำเป็น.
