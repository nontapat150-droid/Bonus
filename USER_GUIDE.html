📋 ผู้ใช้งานทั่วไป

คู่มือสำหรับผู้ใช้งานทั่วไป

คู่มือการใช้งานสำหรับพนักงาน Sales และผู้ใช้งานทั่วไป — เน้นหน้าแรก เช็คอิน และการดูข้อมูล

✅ หน้าแรก ✅ ระบบเช็คอิน 🚫 น้ำมัน/ยานพาหนะ 🚫 ระบบ Dispatch 🚫 คลังสินค้า 🚫 จัดการผู้ใช้ 🚫 ตั้งค่าระบบ

📋 บทบาทของคุณ: ผู้ใช้งานทั่วไป (Sales/User) มีสิทธิ์ใช้งาน หน้าแรก และ ระบบเช็คอิน เท่านั้น เมนูอื่นๆ ไม่แสดงเพื่อความเหมาะสม

1

เข้าสู่ระบบ

🔐

เปิดเว็บเบราว์เซอร์ → เข้า URL ของระบบ → กรอก ชื่อผู้ใช้ และ รหัสผ่าน → กดปุ่ม "เข้าสู่ระบบ"

  • 1เปิดเว็บเบราว์เซอร์ (Chrome, Edge, Safari)
  • 2พิมพ์ URL ของระบบที่แอดมินแจ้งให้
  • 3กรอก ชื่อผู้ใช้ และ รหัสผ่าน ที่ได้รับ
  • 4กดปุ่ม "เข้าสู่ระบบ"
💡

ถ้าเข้าไม่ได้ ตรวจสอบ Caps Lock และช่องว่าง ถ้าลืมรหัสให้ติดต่อ Admin

2

หน้าแรก (Dashboard)

🏠

เมื่อเข้าสู่ระบบแล้ว คุณจะเห็นหน้าแรกที่แสดงข้อมูลสรุปและเมนูด่วน

  • 📢 ประกาศถ้ามีประกาศจาก Admin จะมีป๊อปอัปหรือแถบวิ่งด้านบน อ่านให้ครบก่อนปิด
  • 🔔 แจ้งเตือนกดปุ่มกระดิ่ง 🔔 มุมบนขวาเพื่อดูการแจ้งเตือนจาก Admin
  • 📋 เมนูด่วนกดการ์ด "ระบบเช็คอิน" เพื่อไปยังหน้าเช็คอินโดยตรง
ℹ️

ถ้าเห็นเมนูน้อยกว่าเพื่อนร่วมงาน ไม่ต้องตกใจ — แต่ละบทบาทเห็นเมนูต่างกันตามสิทธิ์

3

การเช็คอินเริ่มงาน

✅

ต้องเช็คอินทุกวันก่อนเริ่มงาน คลิกเมนู ระบบเช็คอิน จากแถบเมนูด้านซ้าย

  • 1คลิกเมนู "ระบบเช็คอิน"
  • 2กดปุ่ม "เช็คอิน" หรือ "เริ่มงาน"
  • 3ถ้าระบบขอตำแหน่ง GPS → กด "อนุญาต"
  • 4สถานะเปลี่ยนเป็น "กำลังทำงาน" สีเขียว = เช็คอินสำเร็จ
⚠️

ต้องเช็คอิน ก่อนเริ่มทำงานทุกวัน ถ้าลืมให้รีบแจ้ง Admin ทันที

4

การเช็คเอาต์เลิกงาน

🏁

เมื่อเลิกงานต้องเช็คเอาต์เพื่อบันทึกเวลาออกงานให้ครบถ้วน

  • 1กลับไปที่เมนู "ระบบเช็คอิน"
  • 2กดปุ่ม "เช็คเอาต์" หรือ "จบงาน"
  • 3กด "ยืนยัน" ในกล่องยืนยัน
  • 4สถานะเปลี่ยนเป็น "เลิกงานแล้ว" = เสร็จสมบูรณ์
✅

ระบบจะบันทึกเวลาเข้า-ออกงานให้อัตโนมัติ ไม่ต้องจดเอง

5

ดูการแจ้งเตือน

🔔

กดปุ่มกระดิ่ง 🔔 ที่มุมบนขวาของหน้า เพื่อดูการแจ้งเตือนจาก Admin และระบบ

  • 🔴 ดอทถ้ามีจุดแดงที่กระดิ่ง แสดงว่ามีแจ้งเตือนที่ยังไม่ได้อ่าน
  • 👁 อ่านกดกระดิ่งเพื่อเปิดดูรายการแจ้งเตือนทั้งหมด
6

ออกจากระบบ

🚪

กดชื่อผู้ใช้ที่มุมซ้ายล่างของเมนู → กด "ออกจากระบบ" ทุกครั้งหลังเลิกงาน

⚠️

ถ้าใช้คอมพิวเตอร์ส่วนกลาง ต้อง logout ทุกครั้ง เพื่อความปลอดภัย

🆘 ปัญหาที่พบบ่อย แก้ได้เอง
อาการที่พบวิธีแก้ไข
เข้าสู่ระบบไม่ได้ พบบ่อย ตรวจสอบ Caps Lock และช่องว่างในชื่อผู้ใช้ ถ้าลืมรหัสผ่านให้ติดต่อ Admin
กดเช็คอินแล้วไม่บันทึก พบบ่อย ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต รีเฟรชหน้า (F5) แล้วลองใหม่ ถ้ายังไม่ได้แจ้ง Admin
ไม่เห็นเมนูบางอัน ผู้ใช้ทั่วไปเห็นเฉพาะเมนูตามสิทธิ์ — เป็นเรื่องปกติ ถ้าคิดว่าขาดสิทธิ์ที่ควรได้ แจ้ง Admin
หน้าจอค้างหรือโหลดช้า ตรวจสอบสัญญาณอินเทอร์เน็ต รีเฟรชหน้า หรือลองปิดแล้วเปิดเบราว์เซอร์ใหม่
ลืมเช็คอิน/เช็คเอาต์ แจ้ง Admin ทันทีพร้อมบอกเวลาที่ถูกต้อง เพื่อให้ Admin บันทึกให้
